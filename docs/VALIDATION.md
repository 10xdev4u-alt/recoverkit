# Validation Playbook — 30 Days, Zero Code

Goal: prove demand and pricing before a single line of production code.

## Week 1 — Landing page + waitlist

- [ ] One-page site: headline, 3-sentence pitch, one mock screenshot, email field
- [ ] Price on the page: "$29/mo flat, no MRR tiers" — filter real intent
- [ ] Ship to: r/SaaS, Indie Hackers, 2-3 "indie SaaS" Discord/Slack communities
- [ ] Target: 50 signups

## Week 2 — Problem interviews

- [ ] DM 15 Stripe SaaS founders from waitlist + communities
- [ ] Ask: "How do you handle failed payments today? What does it cost you?"
- [ ] Do not pitch. Listen for repeated pain, existing spend, workarounds
- [ ] Win condition: 8+ describe the same pain unprompted

## Week 3 — Pricing smoke test

- [ ] Offer "founding member" deal: $10 deposit locks lifetime $29/mo
- [ ] Target: 5+ pre-orders
- [ ] If $0 paid → problem isn't painful enough, kill or reposition

## Week 4 — Scope lock

- [ ] If 5+ paid: freeze MVP to the 6 items in SPEC §6
- [ ] Write the 3 dunning email templates manually (no AI needed yet)
- [ ] First build sprint begins

## Kill / pivot triggers

- < 20 signups by day 14 → reposition or abandon
- < 5 pre-orders by day 30 → do not build the MVP
- Every interview says "Stripe already handles this fine" → exit

## What counts as evidence

- A pre-order beats 100 "cool idea" replies
- Repeated unsolicited complaints > polite interest
- "How much would you pay?" answered without hesitation = strong signal
